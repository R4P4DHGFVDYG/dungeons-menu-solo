# Componentes de terceiros

| Componente | Licença | Uso |
|---|---|---|
| [NeoRuneExtended SDK](https://github.com/thororen1234/NeoRuneExtended) 1.0.0 | MIT | Compila o C# do mod para Blueprint. Vem do NuGet (`NeoRuneExtended.Sdk/1.0.0`); seus helpers de UI e input são compilados junto com o mod |
| NeoRune | MIT | Projeto original do NeoRuneExtended (crédito a NeoMakesGames / NeoPlayzGames) |
| [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons2/mods/2) (ewanhowell5195) | — | Carregador de mods necessário para o menu rodar. Não vem neste repositório nem no pacote de lançamento: o jogador instala pela página dele. Até a 0.3.8 o pacote trazia o BetterBlueprintLoader (GPL-3.0), que não é mais usado |

As ferramentas de build UAssetAPI, retoc, repak e Roslyn são obtidas pelo SDK e não estão neste repositório.

Minecraft Dungeons II e seus recursos pertencem aos respectivos titulares. Este projeto não é afiliado nem endossado pela Mojang Studios ou pela Microsoft. As imagens em `docs/images` são capturas de tela do jogo rodando o mod.
